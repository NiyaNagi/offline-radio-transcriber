## Class B — silently wrong

### F-001 — Every real transmission is persisted with a 1970 timestamp and zero clock fields
- **Class:** B
- **Evidence:** `pipeline/src/main/kotlin/org/ort/pipeline/capture/RealCaptureService.kt:375`
  `startedAtUtc = 0L`; `:376` `endedAtUtc = null`; `:394` `monotonicStartNanos = 0L`; `:395`
  `utcOffsetMinutes = 0`. `RealSegmentSink` is the production sink (`MainActivity.kt:116` starts
  `RealCaptureService`). The same class already has the real wall-clock session start
  (`startedAtWallMillis`, `:109`, `:150`) and the real `samplePosition = record.startSample`
  (`:393`), so the value is derivable. `startedAtUtc` is indexed and drives `ORDER BY` in
  `ActivityDao`/`SearchDao`, the time labels in `TransmissionDetail.kt`, the date-range search
  filter (P15) and the hour-of-day activity pattern (P17). Not mentioned in any CHANGELOG entry
  (grep `startedAtUtc` → no hits).
- **Requirement/principle:** FR-RUN-15..18 (clock model), FR-UI-3 (time-range filter), FR-UI-11,
  constitution I (a log that silently guesses).
- **Owning module(s):** `:pipeline`
- **Fix sketch:** derive `startedAtUtc`/`endedAtUtc` from session wall-clock start plus
  `record.startSample`/`endSample` at 16 kHz via `SampleClock`; record `monotonicStartNanos` from
  the same clock and `utcOffsetMinutes` from the device zone. Pre/post-roll should come from the
  `SegmentConfig` instance rather than the duplicated literals at `:379-380`.
- **Verification:** new `RealSegmentSinkTest` in `pipeline/src/test`, named for FR-RUN-15, asserting
  a closed segment's `startedAtUtc == sessionStart + startSample*1000/16000` and
  `endedAtUtc != null`; `./gradlew :pipeline:test`.
- **Status:** FIXED — 96dc8b2 (merged 7ecaa57)

- **Class:** A

  `dependencyRules` should assert no other manifest does). Split into two agent briefs if the
  manifest change is not trivial.
- **Fix sketch:** a user-initiated "Download models" screen with progress and checksum result,
  writing to the exact paths `AsrEngineProvisioning`/`RealVadProvider` read; a build-time check
