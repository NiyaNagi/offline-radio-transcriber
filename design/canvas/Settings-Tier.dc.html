The tiers
1
Capture and a live transcript
Tiny model only. No voice match, no Pass C, no threads. Attributes only what it hears spelled out plainly — everything else is unknown, not guessed. The field-phone tier.

Fewer transcript errors, inferred attributions, threads. Pass C off — ambiguous overs stay ambiguous rather than resolve from the audio. Where this phone lands when warm.

Pass C resolves callsigns against the audio itself, not the transcript. The most callsigns, and the ones it is least sure of are still marked that way. The only tier that loads the bundled language model — for prose summaries, never for callsigns.
