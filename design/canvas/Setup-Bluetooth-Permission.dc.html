Nearby devices
Bluetooth mode needs one more permission
Android calls it "Nearby devices". It lets the app see which radios are paired and open a serial link to the one you choose. Nothing is scanned for, nothing is advertised, and the app never pairs anything itself — pairing stays in the system Bluetooth settings.
Read the paired-device list
so the rig can be picked by name
Open a serial link to it
the same CAT commands the USB cable carries
Use a Bluetooth headset-class device as the input
only if you choose it on the Input step
Denying it keeps the USB path working
Without this permission the Bluetooth rows on the next steps are shown but cannot be chosen, and the mode falls back to USB. Nothing else changes.
