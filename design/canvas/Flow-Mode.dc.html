The lanes share every other step. Settings › Input and level › Capture mode re-enters the same screens later; a change applies at the next session, never mid-capture.

Changing later — CF02 Input and level › Capture mode → CF11, the same three rows with the current one marked; Change on the Audio route or Rig link rows reopens S04 or S09b directly. With a session live, CF11 carries the amber "applies when it ends" banner.
Independence — a preset is a default, not a coupling. Bluetooth control with cabled audio is the combination no lane names by default and the one S09b steers toward: the CAT data is lossless over Bluetooth, the audio is not.
Failures — Bluetooth audio dropping mid-session is F23; the rig link dropping is F9 with the transport named. Both keep capturing; only the audio drop records a gap.
